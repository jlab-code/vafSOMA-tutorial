# vafSOMA tutorial

A step-by-step introduction to [vafSOMA](https://github.com/jlab-code/vafSOMA), which finds somatic mutations fixed
in one meristem layer of a plant from bulk sequencing of organs, assigns their layer and counts them per organ. It
takes about 45 minutes and is tested with vafSOMA 0.4.3; the example results are the same with vafSOMA 0.3.0 to 0.4.3.

**Read it:** open [`vafSOMA_tutorial.md`](vafSOMA_tutorial.md) on GitHub, or download
[`vafSOMA_tutorial.html`](vafSOMA_tutorial.html) and open it in a browser.

## Contents

1. Install and first run
2. Read the results
3. Replicate organs
4. Your own data (input tables and run configuration)
5. Reference and troubleshooting
